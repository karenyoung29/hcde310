app.py runs a webapp that returns artworks that user searches from the Chicago Institute of Art API, with images, title, artist and year, for student researchers who are interested in analyzing art relating to key words.

How to run: in the terminal, type "python app.py" and open the link, http://127.0.0.1:5000 to run the webapp. Search with any key word and it should return artworks relating to the word if there is any.

Press Ctrl + C to end the run.
